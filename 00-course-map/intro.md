# ACME Corp Kubernetes Academy

Welcome to an **enterprise-style** practice environment. You are onboarding as a Platform Engineer supporting product teams on a shared EKS-like cluster (simulated with kubeadm).

## How this course works

- Scenarios are **short tickets** with verification — click **Check** when you meet the acceptance criteria.
- Use `{{exec}}` buttons in steps to run commands quickly.
- Manifests ship in `~/assets/` when a scenario starts (where configured).
- Progress: **Foundations → Platform → Enterprise → Pro**.

## Mindset

| Level | You should be able to… |
| --- | --- |
| Foundations | Navigate the API, namespaces, basic workloads |
| Platform | Expose services, manage config, understand networking |
| Enterprise | Apply RBAC, debug live issues, enforce guardrails |
| Pro | Schedule across nodes, lead incidents, own a vertical slice |

Click **Start** when ready.
